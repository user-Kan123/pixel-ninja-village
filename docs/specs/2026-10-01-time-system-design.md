# 时间系统设计（子项目 ① · 目标版本 v0.11）

> 本文档是《游戏的想法》在"时间"这条线上的落地设计。
> 原文相关段落：「玩家前期主要是靠小队接任务以及精英上忍老师授课教学来提升自己属性以及学习忍术」
> 「你还可以趁着夜色潜入藏有禁术的机密机构」——即：昼夜必须是**有玩法含义**的，不能只是换张皮。
>
> 范围：只做时间本身。忍术卷轴与研究进度、熟练度、三个界面重做分别是子项目 ②③④。

---

## 1. 决策摘要

| # | 决策 | 来源 |
|---|---|---|
| D1 | 一个游戏日 = **10 分钟**现实时间（白天 8 分 + 夜晚 2 分），星露谷式节奏 | 用户拍板 |
| D2 | 夜晚有**轻度后果**：店铺打烊 + 野外更危险（只变多、不变强） | 用户拍板 |
| D3 | **睡觉**：回到公寓按 E，任何时间都能睡，直接跳到次日 06:00，回满三项资源并存档 | 用户拍板 |
| D4 | **一天只能睡一次**（防"连点睡觉刷研究进度"） | 设计方，用户未反对 |
| D5 | **0:00 之后不昏倒**，改为「熬夜惩罚」：体力消耗加快 | **用户修订** |
| D6 | 店铺 **20:00 打烊**（原提案 18:00） | **用户修订** |
| D7 | 时钟放在 `Flow`（现成全局单例），不新建 autoload | 设计方 |

## 2. 时间刻度

| 时段 | 游戏时间 | 现实时长 | 换算 |
|---|---|---|---|
| 白天 | 06:00 → 18:00 | 8 分钟 | **40 秒 = 1 游戏小时** |
| 夜晚 | 18:00 → 次日 06:00 | 2 分钟 | **10 秒 = 1 游戏小时** |
| 熬夜段 | 00:00 → 06:00 | 1 分钟 | 同上（夜间惩罚生效） |

夜晚刻意走得快（4 倍速），因为村里天黑后没多少可做的事，玩家不该在黑屏里站满 8 分钟。

`hour` 用浮点存在 `Flow` 里（0.0 ~ 24.0），跨天时减 24 并把 `day` +1。

---

## 3. 一天的循环

```
06:00  天亮：亮度恢复，店铺开门，熬夜惩罚解除
18:00  入夜：画面渐暗、野外变危险
20:00  打烊：忍具店 / 一乐拉面 / 甘栗甘 都关门
00:00  深夜：熬夜惩罚开始（体力消耗加快），不昏倒、不传送
06:00  次日：新的一天
```

### 睡觉（D3 / D4）

- 地点：**玩家公寓**（现在那个"休息处"交互点）。
- 效果：时间跳到**次日 06:00**；生命 / 查克拉 / 体力回满；写入存档。
- 限制：**每个游戏日只能睡一次**。"一天"指 `06:00 → 次日 06:00` 这一段（跨 06:00 时重置 `slept_today`）。
  睡过之后再按 E 提示"还睡不着，先过了今天"。
  理由：不加限制的话，玩家在公寓门口连点睡觉，20 秒就能"过"完 15 天，②的"研究十几天"会当场失效。

### 熬夜惩罚（D5）

00:00 之后（`hour >= 0.0 and hour < 6.0`）：

| 项 | 变化 |
|---|---|
| 站立回复体力 | 8/秒 → **2/秒**（几乎回不动） |
| 移动 / 近战 / 投掷 / 忍术的体力消耗 | **×1.5** |

不再有昏倒、传送回公寓、扣赏金。玩家可以用体力硬撑，但撑不久——体力见底会进入已有的**力竭**状态（禁攻击 / 忍术 / 投掷、移速 ×0.45），自然会想回家睡觉。两条系统天然咬合，不额外造惩罚。

## 4. 夜晚的后果（D2 / D6）

| 对象 | 白天 | 夜晚（18:00 后） |
|---|---|---|
| 忍具店 / 一乐拉面 / 甘栗甘 | 正常营业 | 18:00–20:00 仍营业；**20:00 后按 E 提示"已经打烊了，明天再来"** |
| 村外野外（wild） | 正常刷怪 | 刷怪间隔 **×0.7**、精英权重 **×1.5**（只变多，不变强） |
| 村内 | 绝对安全 | **仍然绝对安全**（保留新手保护） |

---

## 5. 画面表现

- **右上角时钟**：`第 3 天 · ☀ 09:20` / `第 3 天 · ☾ 21:40`。
  白天用暖色太阳、夜晚用冷色月亮；字体沿用现有 UI 字体。
  **位置上要腾地方**：战斗 HUD 右上角现在已经有"击倒 N"和"赏金 / 第 N 天"，时钟放到**最上面一行**，
  把这两行整体下移一格（村内 HUD 同理，它右上角目前只有标题）。
- **夜间压暗**：全屏深蓝遮罩，透明度随夜色渐变，最大约 **0.35**；玩家周围保留一圈微光（用同心圆近似径向渐变，避免 shader 依赖）。
- **黄昏/黎明过渡**：18:00 与 06:00 前后各 **30 游戏分钟**内线性渐变，不许"啪"一下黑掉或亮起。
- **HUD 文字精简**：本次只加时钟，不改其它文案；文案精简属于子项目 ④。

## 6. 存档

- 新增 `Flow.hour`，与 `day` 一起写入 `user://pnv_save.json`。
- **老存档兼容**：只有 `day` 没有 `hour` → 读成 `06:00`。
- 另存一个"本日已睡"标记（`slept_today`），同样进存档。
- **任务完成不再自动 `day += 1`**：时间交给时钟，任务只是"花掉了真实经过的那段时间"。

## 9. 验收标准

1. 站着不动 8 分钟：天从亮到黑，右上角从 `06:00` 走到 `18:00`。
2. 20:00 后走到忍具店 / 一乐拉面按 E → 提示打烊，打不开界面。
3. 公寓按 E 睡觉 → 次日 `06:00`、三项回满、已存档；同一天再按 E 提示"还睡不着"。
4. 00:00 后在村外：**不会**被传送回村、**不会**扣钱；体力掉得明显更快，容易进入力竭。
5. 夜间野外刷怪比白天更密（可观测：同样时间里敌人数更多）。
6. 任务完成不再凭空 +1 天，时间只按实际经过流逝。
7. 老存档（无 `hour` 字段）能正常读取，从 `06:00` 开始。
8. 以上全部进 `selftest.gd`，`SELFTEST OK`。

---

## 10. 明确不做（避免范围蔓延）

- 不做"昏倒/被送回家"（用户已否决）。
- 不做夜里敌人的数值强化（只调数量与概率）。
- 不做"趁夜色潜入禁术库"（等身份线子项目；本次只在 `is_late_night()` 上留接口）。
- 不改任务结算界面、不改背包与忍术界面（属于子项目 ④）。
- 不做季节、星期、天气。
