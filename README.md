# 像素忍者村 / Pixel Ninja Village

火影忍者题材的像素沙盒 RPG —— **免费同人开源作品，仅供娱乐，不商业化**。

当前状态：**战斗原型 v0.2**（俯视视角 · 纯色块占位美术 · 10 个数据驱动忍术 · 等级成长 · 装配系统）
v0.1 → v0.2 的变化：忍术从 2 个扩到 10 个（覆盖全部 8 个原型类别）、新增蓄力/坐标选择/引导三类施法管线、新增经验与等级（1-20）、忍术槽 3→5 随等级解锁、装配界面、两种新敌人（远程射手 / 重型）、无头自检脚本。

## 运行

1. 安装 [Godot 4.4+](https://godotengine.org/download) 标准版（无需 .NET 版）
2. 用 Godot 打开本目录的 `project.godot`，按 F5 运行
3. 或命令行：`godot --path <本目录>`

无头自检（改完代码后先跑这个，能抓到绝大多数低级错误）：

```
godot --headless --path . --fixed-fps 60 --quit-after 12000 res://tests/selftest.tscn
```

看到 `SELFTEST OK` 即通过；失败会列出具体用例。

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标左键 | 近战攻击（三连击，第三段为重击）／忍术瞄准中为“释放”／选点中为“放置” |
| 鼠标右键 | 投掷苦无（限量，自动补充）／取消结印瞄准、蓄力、选点 |
| 1-5 | 释放对应槽位的忍术（槽位内容可在装配界面改） |
| Tab | 打开/关闭忍术装配界面（游戏暂停） |
| R | 重新开始 |

槽位解锁：1-3 槽天生可用，**6 级解锁第 4 槽，12 级解锁第 5 槽**。

## 忍术一览（10 个）

| 忍术 | 类别 | 施法方式 | 说明 |
|---|---|---|---|
| 瞬身术 | 位移 | 瞬时 | 朝鼠标冲刺，带无敌帧 |
| 火遁·小火弹 | 投射物 | 结印瞄准 | 结印 → 瞄准 → 点目标，小范围爆炸 + 灼烧 |
| 火遁·豪火球 | 投射物 | 蓄力 | 按住蓄力，火球越大伤害/范围/灼烧越强 |
| 雷遁·雷光突刺 | 位移 | 蓄力 | 蓄力冲刺，沿途撞到的敌人全部受伤，冲刺距离随蓄力量增长 |
| 影分身之术 | 召唤 | 瞬时 | 召出 2 个影分身自动索敌挥刀，12 秒后消失 |
| 雷遁·雷刃 | 自身强化 | 瞬时 | 8 秒内近战附带额外伤害与麻痹（定身） |
| 医疗术 | 治疗 | 引导 | 按住持续回血、持续消耗查克拉，被打断即中止 |
| 土遁·土流壁 | 领域 | 坐标选择 | 在选定位置召出土墙，阻挡敌人并可被啃坏（有耐久） |
| 封印术·封缚印 | 封印 | 坐标选择 | 在选定位置张开封印领域，范围内敌人被定身 |
| 幻术·狐惑 | 幻术 | 瞬时 | 范围敌人陷入混乱，改为随机游走、停止攻击 |

**施法管线只认 `cast_type`**：瞬时 / 结印瞄准 / 蓄力 / 坐标选择 / 引导。五个管线已经全部被这 10 个忍术覆盖并跑通，后续加新忍术基本是“填参数 + 复用管线”。

## 玩什么

训练场里有四种敌人：

- **木桩**：不动，测连招与忍术伤害
- **追击型**：会追、会预警（感叹号）、会挥击
- **远程射手**：保持中距离投掷苦无，会横移绕走
- **重型**：血厚、移动慢、0.8 秒大范围横扫预警，伤害与击飞极高，受击硬直被大幅压制（打不断，要用走位/定身/幻术处理）

敌人会按累计击倒数重生，难度缓慢爬升：木桩与追击者比重下降，射手与重型比重上升。
击杀获得经验，升级提升体力/查克拉上限并在 6 级、12 级解锁忍术槽。

现在的目标是验证：三连击跟不跟手、重击有没有分量、瞬身好不好用、敌人追击的压迫感对不对、**五条施法管线的手感差异是否成立**。

## 工程结构

```
project.godot        工程配置（Godot 4.4）
scenes/main.tscn     主场景
scripts/             逻辑
  player.gd          玩家（5 条施法管线 + 成长 + 装配读表）
  enemy_base.gd      敌人基类（受击/灼烧/击退/定身/混乱）
  enemy_dummy.gd     木桩
  enemy_chaser.gd    追击型
  enemy_shooter.gd   远程射手
  enemy_brute.gd     重型
  projectile.gd      通用投射物（敌方投射物通过 hostile 标记）
  earth_wall.gd      土流壁（可破坏墙体）
  binding_field.gd   封缚领域
  shadow_clone.gd    影分身召唤物
  loadout_ui.gd      忍术装配界面（Tab）
  hud.gd             血条/查克拉/经验/忍术槽
  data.gd            数据加载 + 忍术图标
data/jutsu.json      忍术表（10 条）
data/strings.json    名词表（换皮层：专有名词不进代码）
tests/selftest.gd    无头自检用例
```

忍术框架：每个忍术 = 原型类别（投射物/自身强化/位移/召唤/幻术/封印/治疗辅助/领域持续）+ 施法方式 + 一行参数。**新增一个忍术 = 往 `data/jutsu.json` 加一条 + 在 `strings.json` 补个名字**，不需要动逻辑代码。
