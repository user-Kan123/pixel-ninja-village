# 像素忍者村 / Pixel Ninja Village

火影忍者题材的像素沙盒 RPG —— **免费同人开源作品，仅供娱乐，不商业化**。

当前状态：**战斗原型 v0.1**（俯视视角 · 纯色块占位美术 · 数据驱动忍术）

## 运行

1. 安装 [Godot 4.4+](https://godotengine.org/download) 标准版（无需 .NET 版）
2. 用 Godot 打开本目录的 `project.godot`，按 F5 运行
3. 或命令行：`godot --path <本目录>`

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标左键 | 近战攻击（三连击，第三段为重击） |
| 鼠标右键 | 投掷苦无（限量，自动补充） |
| 1 | 瞬身术（朝鼠标方向冲刺，带无敌帧） |
| 2 | 火遁·小火弹（结印 → 瞄准 → 点目标释放，小范围爆炸 + 灼烧） |
| R | 重新开始 |

## 玩什么

训练场里有两种敌人：**木桩**（测连招与忍术伤害）和**追击型敌人**（会追、会预警、会挥击，攻击前有感叹号提示）。敌人会重生，目标是验证战斗手感的四件事：三连击跟不跟手、重击有没有分量、瞬身好不好用、敌人追击的压迫感对不对。

## 工程结构

```
project.godot        工程配置（Godot 4.4）
scenes/main.tscn     主场景
scripts/             逻辑（玩家/敌人/投射物/特效/HUD/数据）
data/jutsu.json      忍术表（8 原型类别 × 6 施法方式的参数化实现）
data/strings.json    名词表（换皮层：专有名词不进代码）
```

忍术框架：每个忍术 = 原型类别（投射物/位移/强化/召唤/幻术/封印/辅助/领域）+ 施法方式（瞬时/结印+瞄准/附身/蓄力/选点/被动）+ 一行参数。新增忍术只需往 `data/jutsu.json` 加条目。

## 路线图

战斗原型 → 垂直切片（村庄 + D 级任务闭环 + 成长存档）→ 忍术框架扩充 → 内容填充。
