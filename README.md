# 像素忍者村 / Pixel Ninja Village

火影忍者题材的像素沙盒 RPG —— **免费同人开源作品，仅供娱乐，不商业化**。

当前状态：**垂直切片 v0.7**（装备与忍具：4 件忍具 + 2 个武器槽 + 左上角武器槽 HUD + B 键「装备与背包」+ 忍具店；像素角色 + 扩建村庄 + 野外任务场景 + 任务指引 + 成长存档 + 15 个数据驱动忍术）

- v0.6 → v0.7 的变化：
  - **忍具与武器槽**：手里剑 / 苦无 / 短刀 / 长剑，数值全部走 `data/weapon.json`；2 个武器槽（主手 / 副手），`Q` 切换
  - **左上角武器槽 HUD**：血条下面常驻两块，当前手持的那块高亮并显示投掷余量 `x N / M` —— 不打开任何界面就知道手里拿的是什么
  - **`B` 打开「装备与背包」**（原 `Tab` 的功能合并进来）：**武器 / 忍具**页装配忍具、**忍术装配**页装配忍术；面板内 `Tab` 切页签
  - **忍具店**：走到村东忍具店门口按 `E` 购买，花赏金买下的忍具自动进背包并占一个空武器槽
  - **开局发 150 两**（原构想里的"少量金钱"），先买得起手里剑
  - 近战伤害 / 范围 / 攻速与投掷弹道全部按手持忍具结算：手里剑只能投掷，短刀与长剑只能近战，苦无两用
  - 玩家手里会画出当前忍具，刀光弧线也随忍具范围变化
  - 自检新增忍具数值梯度、投掷、切换、装配规则、商店购买与存档回读

- v0.5 → v0.6 的变化：
  - **新增测试模式，默认开启**：无视等级，**15 个忍术全部可用、5 个忍术槽全部解锁**，方便把所有内容都测一遍
  - 游戏内按 **`F1`** 随时开/关；两套 HUD 左下角与忍术装配界面都会显示当前状态
  - 关掉后立刻回到正式进度（1 级 3 槽 / 6 级 4 槽 / 12 级 5 槽）
  - ⚠️ 正式发布前把 `scripts/flow.gd` 的 `test_unlock_all` 改成 `false`（或删掉这个开关与 `player.slots_unlocked()` 里的分支）
  - 自检补了测试模式的回归：5 个槽逐个按键都要真的进入施法、关掉开关后第 5 槽按键无反应、`F1` 真实按键能来回切换

- v0.4 → v0.5 的变化：
  - **移动改为鼠标跟随**：人物朝光标方向走，越近越慢，光标压在人物身上即站住；WASD 保留为叠加微调（详见下方「操作」）
  - **主角与敌人移动速度统一降到原来的 60%**：主角 330 → 198 px/s，追击型 175 → 105，重型 108 → 65，射手走位 150 → 90，精英 142 → 85，影分身 250 → 150
  - **修复界面点击完全无效**：挂在 CanvasLayer 上的 Control 只调 `set_anchors_preset` 不会撑开尺寸，`size` 停在 (0,0) —— 界面画得出来但鼠标命中测试永远失败。任务看板与忍术装配界面都受此影响，改用 `set_anchors_and_offsets_preset`
  - **修复 HUD 右侧文本跑出屏幕**：`draw_string` 只在 `width > 0` 时才应用对齐，传 `-1` 会让 `HORIZONTAL_ALIGNMENT_RIGHT` 退化成左对齐，文本从右边界继续往右画（击杀数 / 赏金 / 天数 / 操作提示 / 标题都中招）
  - **忍术装配界面重排到一屏内**：2 列 × 8 行、面板 1010×664，15 个忍术不再有行被挤出屏幕
  - **忍术装配有独立入口**：`Tab` 随时打开（与任务看板无关），村庄 HUD 常驻提示

- v0.3 → v0.4 的变化：
  - **角色全部像素化**：玩家与 5 种敌人从纯色方块改为可辨认的像素忍者（`scripts/pixel_art.gd` 程序化绘制，带走路动画）
  - **村庄扩建**：4 → 8 座风格化建筑（俯视瓦屋顶 + 门窗招牌）、火影岩、出村大门、道路广场网、路灯树木灌木
  - **新增野外场景**：任务在村外草地执行（`scenes/wild.tscn`），训练场保留为自由练习
  - **任务流程接通**：看板接取 → 走到**出村大门**按 E 出发（待出发时大门发光）
  - **任务指引**：任务开始横幅、屏幕外目标指示箭头、情报卷轴竖直光柱，解决"找不到目标、任务完不成"
  - 战场重构为可继承的 `Battlefield` 基类，新增场景只需覆写尺寸 / 障碍 / 地表

## 运行

1. 安装 [Godot 4.4+](https://godotengine.org/download) 标准版（无需 .NET 版）
2. 用 Godot 打开本目录的 `project.godot`，按 F5 运行（启动进入村庄）
3. 或命令行：`godot --path <本目录>`

无头自检（改完代码后先跑这个）：

```
godot --headless --path . --fixed-fps 60 --quit-after 20000 res://tests/selftest.tscn
```

看到 `SELFTEST OK` 即通过（110+ 断言：忍术管线/效果/被动/螺旋丸/拾取/墙体/分身/敌人攻击/成长/测试模式/装备与忍具（武器槽、四种忍具的数值梯度、投掷与回手、Q 切换、装配规则、忍具店购买）/鼠标跟随/存档读写/三类任务流/野外场景与待出发流程/界面可点性/死亡）。

> 新增 `class_name` 后先跑一次 `godot --headless --path . --import` 注册全局类；自检务必带 `--fixed-fps 60`，否则按帧/按时间的判定会因机器性能误报；再带 `--quit-after` 兜底，避免用例挂死时进程不退出。

## 怎么玩

**村庄（据点）**：
1. 走到**任务看板**（任务领取处旁）按 E，选择一条 D 级任务；
2. 按提示走到南侧**出村大门**（接任务后会发光），按 E 出发前往野外；
3. **训练场入口**（红色鸟居）按 E 可自由练习；**休息处**按 E 保存进度；
4. **忍具店**（村东的摊位）按 E 花赏金买忍具，买完按 `B` 装到武器槽。`B` 随时打开「装备与背包」（换武器 / 换忍术）。

**任务（3 条 D 级，可重复接，均在野外执行）**

| 任务 | 玩法 |
|---|---|
| 清理入侵者 | 讨伐 10 名敌人（持续补充，含少量精英） |
| 村外阻击战 | 拦截 3 波来袭敌人，最后一波有精英带队 |
| 回收情报卷轴 | 在骚扰中回收 6 份卷轴（卷轴有光柱，远处可见） |

野外找不到目标时，屏幕边缘有箭头指向最近目标。
完成 → 赏金 + 经验 + 过一天 → 按 E 回村；阵亡 → 任务失败回村，**不删档**。

## 操作

| 按键 | 功能 |
|---|---|
| 移动鼠标 | 主移动方式：人物朝鼠标方向自动走，越靠近鼠标越慢，鼠标贴到人物身上即站住 |
| WASD | 备用移动，与鼠标方向叠加，用于微调走位 |
| 鼠标左键 | 近战三连击（第三段重击）／瞄准中释放／选点中放置 |
| 鼠标右键 | 投掷当前忍具（手里剑 / 苦无）／取消结印瞄准、蓄力、选点 |
| 1-5 | 释放对应槽位忍术（被动忍术装配即生效，无需按键） |
| Q | 切换主手 / 副手武器 |
| E | 交互（看板/大门/训练场/休息处/忍具店/任务结算回村） |
| B | **装备与背包**：村庄 / 野外 / 训练场随时可开。左键点左侧槽位（武器槽或忍术槽）选中、点右侧卡片装入、右键点槽位卸下；面板内 `Tab` 在「武器 / 忍具」与「忍术装配」两页之间切换，`B` / `Esc` 关闭 |
| R | 重开当前场景 |
| **F1** | **测试模式开关**：开启时 15 个忍术全部可用、5 个忍术槽全部解锁（默认开启）；关闭后恢复按等级解锁。装配界面打开时同样可用 |

> 移动细节（`player.gd` 顶部常量）：鼠标距人物 **24 像素**以内算"站住"；出了死区后在 **60 像素**内线性加速到全速，最低不低于全速的 35%，不会龟速蹭。施法期间（结印/瞄准/蓄力/选坐标/引导）移动速度统一降到 **三成**，避免瞄准远处目标时被自己带着跑。

## 忍具一览（4 件）

两把武器槽（主手 / 副手）各装一件，`Q` 切换；近战与投掷都按手持忍具结算。

| 忍具 | 价格 | 用法 | 特点 |
|---|---|---|---|
| 手里剑 | 40 两 | 只能投掷 | 便宜、出手快、伤害低：投掷 6，携带 14，回手 1.8s |
| 苦无 | 90 两 | 近战 + 投掷 | 最均衡：近战 ×1.00、范围 ×0.90、攻速 ×1.00；投掷 10，携带 8，回手 3.5s |
| 短刀 | 160 两 | 只能近战 | 近战 ×1.35、范围 ×1.00（比苦无长）、攻速 ×1.05 |
| 长剑 | 260 两 | 只能近战 | 近战 ×1.40（与短刀相当）、范围 ×1.38（明显更长）、攻速 ×0.78（更慢） |

> 「近战 ×1.00」是相对基础连招（三段 8 / 9 / 18）的倍率；「范围 ×1.00」= 76 px。改数值只改 `data/weapon.json`，代码一行不动。
> 开局自带一把苦无 + 150 两，其余三件去忍具店买。武器槽数量固定 2 个（将来要加第三槽只改 `Player.WEAPON_SLOT_COUNT`）。

## 忍术一览（15 个）

| 忍术 | 类别 | 施法方式 | 说明 |
|---|---|---|---|
| 瞬身术 | 位移 | 瞬时 | 朝鼠标冲刺，带无敌帧 |
| 火遁·小火弹 | 投射物 | 结印瞄准 | 结印 → 瞄准 → 点目标，爆炸 + 灼烧 |
| 火遁·豪火球 | 投射物 | 蓄力 | 蓄力越大，伤害/范围/灼烧越强 |
| 雷遁·雷光突刺 | 位移 | 蓄力 | 蓄力冲刺，沿途敌人全部受伤 |
| 影分身之术 | 召唤 | 瞬时 | 2 个分身自动索敌，持续 12 秒 |
| 雷遁·雷刃 | 自身强化 | 瞬时 | 8 秒内近战附带麻痹定身 |
| 医疗术 | 治疗 | 引导 | 按住持续回血耗蓝，受击打断 |
| 土遁·土流壁 | 领域 | 坐标选择 | 召墙阻挡敌人，可被啃坏 |
| 封印术·封缚印 | 封印 | 坐标选择 | 范围敌人定身 |
| 幻术·狐惑 | 幻术 | 瞬时 | 范围敌人混乱游走 |
| 螺旋丸 | 自身强化 | 附身触发 | 手持丸子 4 秒，接触敌人引爆大击退（持丸期间不能出刀） |
| 写轮眼·洞察 | 自身强化 | 被动常驻 | 25% 概率免伤闪避 |
| 替身术 | 位移 | 被动常驻 | 致死伤免死一次 + 后撤无敌（冷却 60 秒） |
| 查克拉活性 | 自身强化 | 被动常驻 | 查克拉回复 ×1.6 |
| 怪力术 | 自身强化 | 被动常驻 | 近战伤害 ×1.3 |

**六条施法管线（瞬时/结印瞄准/蓄力/坐标选择/引导/附身触发/被动常驻）已全部落地并各有两个以上样本。** 新增忍术 = `data/jutsu.json` 加一条 + `strings.json` 补个名字。

被动忍术也占忍术槽——带几个主动、留几个被动，本身就是装配策略。

## 敌人（5 种）

木桩 / 追击型（红发）/ 远程射手（灰发，横移绕走 + 投掷）/ 重型（紫衣大横扫、硬直被压制）/ **精英**（黑发晓袍，重型变体：更厚更快 + 中距离三连苦无扇，高经验）。
击杀有 28% 概率掉落回血药或查克拉药。

## 工程结构

```
project.godot        工程配置（autoload：Data 数据 / Flow 流程与存档）
scenes/village.tscn  村庄（主场景）
scenes/main.tscn     训练场（自由练习）
scenes/wild.tscn     野外（任务战场）
scripts/flow.gd      场景切换、任务状态（含待出发 pending）、金钱天数、user://pnv_save.json 存档
scripts/village.gd  村庄布局、建筑与交互点
scripts/main.gd      Battlefield 战场基类（任务三类驱动：讨伐/波次/收集）
scripts/wild.gd      野外场景（覆写地表/障碍/边界）
scripts/pixel_art.gd 程序化像素角色绘制器
scripts/player.gd    玩家（6 条施法管线 + 被动系统 + 成长 + 武器槽与忍具结算）
scripts/loadout_ui.gd 装备与背包界面（B）：武器页 + 忍术页
scripts/shop_ui.gd   忍具店界面（村庄按 E 打开）
scripts/pickup.gd    拾取物（情报光柱 / 回血 / 回蓝）
data/jutsu.json      忍术表（15 条）
data/weapon.json     忍具表（4 件：手里剑 / 苦无 / 短刀 / 长剑）
data/mission.json    任务表（3 条）
data/strings.json    名词表（换皮层：专有名词不进代码）
tests/selftest.gd    无头自检用例（110+ 断言）
tools/shot_roles.gd  开发工具：排列角色自动截图到 user://roles.png
tools/shot_ui.gd     开发工具：装备界面 / 忍术页 / 忍具店 / 战斗 HUD 自动截图
```
