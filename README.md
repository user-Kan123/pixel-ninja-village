# 像素忍者村 / Pixel Ninja Village

火影忍者题材的像素沙盒 RPG —— **免费同人开源作品，仅供娱乐，不商业化**。

当前状态：**垂直切片 v0.11**（**时间系统**：一天 10 分钟的昼夜循环、右上角时钟、夜里压暗、20:00 打烊、夜间野外更危险、回公寓睡觉跳次日；外加木叶村 v4.1 贴图 / 体力系统 / 背包消耗品 / 装备忍具 / 任务闭环 / 成长存档 / 15 个数据驱动忍术）

## 运行

1. 安装 [Godot 4.4+](https://godotengine.org/download) 标准版（无需 .NET 版）
2. 用 Godot 打开本目录的 `project.godot`，按 F5 运行（启动进入村庄）
3. 或命令行：`godot --path <本目录>`

无头自检（改完代码后先跑这个）：

```
godot --headless --path . --fixed-fps 60 --quit-after 20000 res://tests/selftest.tscn
```

看到 `SELFTEST OK` 即通过（140+ 断言：忍术管线/效果/被动/螺旋丸/拾取进背包/墙体/分身/敌人攻击/成长/测试模式/装备与背包（24 格上限、16 个一组、真消耗品投掷、耐久磨损与报废、武器槽指向背包格、Q 切换、兵粮丸、买 1 买 10、赏金与背包空间双重限制）/鼠标跟随/存档读写/三类任务流/野外场景与待出发流程/界面可点性/死亡）。

> 新增 `class_name` 后先跑一次 `godot --headless --path . --import` 注册全局类；自检务必带 `--fixed-fps 60`，否则按帧/按时间的判定会因机器性能误报；再带 `--quit-after` 兜底，避免用例挂死时进程不退出。

## 怎么玩

**村庄（据点）**：
1. 走到**任务看板**（任务领取处旁）按 E，选择一条 D 级任务；
2. 按提示走到南侧**出村大门**（接任务后会发光），按 E 出发前往野外；
3. **训练场入口**（红色鸟居）按 E 可自由练习；**休息处**按 E 保存进度；
4. **忍具店**（村东的摊位）按 E 花赏金买忍具，买完按 `B` 装到武器槽。`B` 随时打开「装备与背包」（换武器 / 换忍术）。
5. **一乐拉面 / 甘栗甘** 按 E 进店买吃的（拉面 35 两、丸子 18 两、饭团 10 两），吃下去回**体力**——体力见底会"力竭"，攻击和忍术都用不了。
6. **回公寓按 E 睡觉**：直接跳到次日早上 06:00，三项资源回满并存档（一天只能睡一次）。右上角时钟能看到第几天、几点；**20:00 后店铺打烊**，**夜里野外更危险**（刷怪更密），**撑到 00:00 之后体力会掉得更快**。

**任务（3 条 D 级，可重复接，均在野外执行）**

| 任务 | 玩法 |
|---|---|
| 清理入侵者 | 讨伐 10 名敌人（持续补充，含少量精英） |
| 村外阻击战 | 拦截 3 波来袭敌人，最后一波有精英带队 |
| 回收情报卷轴 | 在骚扰中回收 6 份卷轴（卷轴有光柱，远处可见） |

野外找不到目标时，屏幕边缘有箭头指向最近目标。
完成 → 赏金 + 经验 + 过一天 → 按 E 回村；阵亡 → 任务失败回村，**不删档**。

## 操作

| 按键 | 功能 |
|---|---|
| 移动鼠标 | 主移动方式：人物朝鼠标方向自动走，越靠近鼠标越慢，鼠标贴到人物身上即站住 |
| WASD | 备用移动，与鼠标方向叠加，用于微调走位 |
| 鼠标左键 | 近战三连击（第三段重击）／瞄准中释放／选点中放置 |
| 鼠标右键 | 投掷当前忍具（手里剑 / 苦无）——扔一枚少一枚／取消结印瞄准、蓄力、选点 |
| 1-5 | 释放对应槽位忍术（被动忍术装配即生效，无需按键） |
| Q | 切换主手 / 副手武器 |
| F | 吃掉背包里第一个可用的道具（兵粮丸 / 回力药 / 查克拉药） |
| E | 交互（看板/大门/训练场/休息处/忍具店/任务结算回村） |
| B | **装备与背包**：村庄 / 野外 / 训练场随时可开。装备页点背包里的忍具 = 装到选中的武器槽、点道具 = 直接使用、右键点武器槽 = 卸下；忍术页点左侧槽位选中 → 点右侧卡片装入。面板内 `Tab` 切页签，`B` / `Esc` 关闭 |
| R | 重开当前场景 |
| **F1** | **测试模式开关**：开启时 15 个忍术全部可用、5 个忍术槽全部解锁（默认开启）；关闭后恢复按等级解锁。装配界面打开时同样可用 |

> 移动细节（`player.gd` 顶部常量）：鼠标距人物 **24 像素**以内算"站住"；出了死区后在 **60 像素**内线性加速到全速，最低不低于全速的 35%，不会龟速蹭。施法期间（结印/瞄准/蓄力/选坐标/引导）移动速度统一降到 **三成**，避免瞄准远处目标时被自己带着跑。

## 忍具一览（4 件）

两把武器槽（主手 / 副手）各装一件，`Q` 切换；近战与投掷都按手持忍具结算。

| 忍具 | 价格 | 用法 | 堆叠 | 耐久 | 特点 |
|---|---|---|---|---|---|
| 手里剑 | 8 两 | 只能投掷 | 16 / 格 | 无 | 便宜、出手快；**扔出去就没了**，投掷伤害 6 |
| 苦无 | 15 两 | 近战 + 投掷 | 16 / 格 | 40 | 最均衡；扔了就没，近战 ×1.00、范围 ×0.90；投掷伤害 10 |
| 短刀 | 160 两 | 只能近战 | 不可堆叠 | 100 | 近战 ×1.35、范围 ×1.00（比苦无长）、攻速 ×1.05 |
| 长剑 | 260 两 | 只能近战 | 不可堆叠 | 140 | 近战 ×1.40（与短刀相当）、范围 ×1.38（明显更长）、攻速 ×0.78（更慢） |

**道具（`data/item.json`）**

| 道具 | 价格 | 堆叠 | 效果 |
|---|---|---|---|
| 兵粮丸 | 20 两 | 16 / 格 | 立刻回 25 体力 + 25 查克拉（`F` 键或背包里点一下） |
| 回力药 | 敌人掉落 | 16 / 格 | 回 30 体力 |
| 查克拉药 | 敌人掉落 | 16 / 格 | 回 35 查克拉 |

> 三条规则记在 `data/weapon.json` / `data/item.json` 里，代码一行不动就能加"起爆符""毒苦无"这类新东西：
> 「近战 ×1.00」是相对基础连招（三段 8 / 9 / 18）的倍率，「范围 ×1.00」= 76 px；
> **可堆叠的东西本来就便宜、不可堆叠的近战武器才是真投资**——短刀长剑可以重复买，每一把的耐久是分开记的。
> 开局发 8 把苦无 + 6 枚手里剑 + 3 颗兵粮丸 + 150 两。武器槽固定 2 个（要加第三槽只改 `Player.WEAPON_SLOT_COUNT`）。

## 敌人（5 种）

木桩 / 追击型（红发）/ 远程射手（灰发，横移绕走 + 投掷）/ 重型（紫衣大横扫、硬直被压制）/ **精英**（黑发晓袍，重型变体：更厚更快 + 中距离三连苦无扇，高经验）。
